# 蒙德里安·Metro 风格 Todo List

一个融合蒙德里安艺术风格与 Windows Phone Metro 风格的现代化 Todo List 应用，具备 Trello 风格的拖拽看板功能。

## 设计理念

### 蒙德里安元素
- **原色系统**：红(#E63946)、黄(#F4D35E)、蓝(#457B9D)
- **黑色网格线**：3px 粗边框分隔
- **几何平衡**：不对称的网格布局

### Metro 风格
- **活动磁贴**：动态信息展示、翻转动画
- **无边框设计**：全屏沉浸式体验
- **大字体层级**：Segoe UI Light 字体系统
- **动态磁贴**：实时更新、翻转效果

## 核心功能

### 1. 活动磁贴系统
- **拖拽排序**：支持拖拽重新排列任务顺序
- **磁贴尺寸**：小(1x1)、中(2x1)、宽(2x2)、大(3x2)
- **动态翻转**：点击翻转查看详情
- **实时动画**：添加、完成、删除动画效果

### 2. Trello 风格看板（四象限视图）
```
┌─────────────────┬─────────────────┐
│   重要且紧急     │   重要不紧急     │
│   (立即做)       │   (计划做)       │
│     红色区       │     黄色区       │
├─────────────────┼─────────────────┤
│   不重要紧急     │   不重要不紧急   │
│   (委托做)       │   (不要做)       │
│     蓝色区       │     白色区       │
└─────────────────┴─────────────────┘
```
- **拖拽移动**：任务可在四象限间拖拽移动
- **优先级自动更新**：拖拽后自动调整优先级
- **看板式管理**：直观的工作量分布

### 3. 手势操作

| 手势 | 操作 | 说明 |
|------|------|------|
| 左滑 | 标记完成 | 任务向左滑动，绿色遮罩 |
| 右滑 | 删除任务 | 任务向右滑动，红色遮罩 |
| 长按 | 多选模式 | 进入批量选择状态 |
| 拖拽 | 排序/移动 | 磁贴墙内排序或看板间移动 |
| 下拉 | 刷新列表 | 重新加载任务数据 |

### 4. 视图切换
- **磁贴墙视图**：瀑布流展示所有任务
- **四象限视图**：艾森豪威尔矩阵管理
- **日历视图**：按日期查看任务分布，支持农历、24节气、中美假日显示

- **农历显示**：支持1900-2100年农历转换，显示农历日期和干支纪年
- **24节气**：显示立春、雨水、惊蛰、春分等24个传统节气
- **中国传统节日**：春节、元宵节、龙抬头、端午节、七夕、中秋节、重阳节、腊八节、除夕
- **中国法定假日**：元旦、春节、清明节、劳动节、端午节、中秋节、国庆节
- **美国法定假日**：新年、马丁·路德·金日、总统日、阵亡将士纪念日、独立日、劳动节、哥伦布日、退伍军人节、感恩节、圣诞节、复活节、母亲节、父亲节

## 技术特性

### 拖拽功能实现
- **HTML5 Drag API**：桌面端原生拖拽
- **Touch Events**：移动端触摸拖拽
- **视觉反馈**：拖拽时半透明、目标高亮
- **数据同步**：拖拽后自动保存排序

- **磁贴翻转**：3D Y轴旋转180°
- **入场动画**：错开延迟的缩放效果
- **手势反馈**：滑动时的实时阴影变化
- **状态过渡**：完成/删除时的平滑动画

## 使用说明

### 安装与运行
1. 克隆或下载项目文件
2. 在浏览器中打开 `index.html`
3. 无需服务器，纯前端运行

### 基本操作
- **添加任务**：点击右下角红色 + 按钮
- **完成任务**：左滑磁贴或点击详情中的完成按钮
- **删除任务**：右滑磁贴或点击详情中的删除按钮
- **编辑任务**：点击磁贴打开详情面板，再点击编辑
- **排序任务**：在磁贴墙视图拖拽磁贴到目标位置
- **看板管理**：切换到四象限视图，拖拽任务到不同象限

### 快捷键
- `Ctrl + N`：新建任务
- `/`：聚焦搜索框
- `Esc`：关闭模态框或详情面板
